AI Agent 與 MCP2026

MCP Relay & Camera Tools

用一個 Cloudflare Worker 搭配 Windows bridge，把家裡好幾個本機 MCP server 安全地開給遠端 AI；其中攝影機 MCP 讓 AI 能看畫面、轉鏡頭、聽聲音和對講。

Why

為什麼做

家裡的 MCP 各自跑法不同。我想讓遠端 AI 能用到它們，同時讓每個服務保有自己的授權、程序與資料，不必每多一個工具就重做整套對外連線。

What I built

我做了什麼

  • Relay：各服務各自保有 OAuth、HTTP session、自動啟動和行程清理（Windows Job Object），密鑰用 DPAPI 保護；relay 本身只管傳輸、驗證和生命週期。
  • 攝影機 MCP：15 個工具，結合本機 Whisper（CUDA）語音轉文字、OpenCV 人形偵測、Windows TTS，以及 MCP 原生影像和音訊回傳。
  • 逆向攝影機的雲台控制指令，接進自己編譯的 go2rtc。

Engineering

我碰到的工程問題

  • 共走同一條對外入口，各服務仍保留自己的 OAuth 與 session；stdio 子程序交給 Windows Job Object 託管，關掉時連同程序樹一起清乾淨。
  • 工具會回傳能讓 Agent 接續自救的錯誤提示，並區分即時畫面與歷史重播，避免卡住時一直盲目重送。
  • 從本機單元測試、Windows bridge 到 Cloudflare Worker 遠端客戶端分層驗證，確保每個新增的本機 MCP 工具接入就能穩定運作。

Role & AI

我和 AI 怎麼分工

工具合約、權限邊界與驗收條件由我定義，實作交給 coding agents 推進；所有家庭影像和設定全部留在本機。

Outcome

成果

共用 Relay 已穩定接上 Coding、Anki 與攝影機服務並每日運作，遠端 AI 可直接呼叫家裡的本機工具與攝影機控制。
