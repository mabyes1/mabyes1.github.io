系統與裝置2026

VibeDeck

把家裡閒置的手機、平板和電子紙拿來當 Windows 真實延伸螢幕或資訊看板，內建主機監控與各家 AI 額度儀表板，也能直接從手機遠端操控電腦。

Why

為什麼做

抽屜裡總有幾台閒置手機、平板和電子紙。想讓它們重新派上用場，就得把「多一塊 Windows 螢幕」跟「遠遠瞄一眼資訊」當成兩種完全不同的模式來設計。

What I built

我做了什麼

  • Windows Host 搭配瀏覽器客戶端，副裝置不用另外裝 App。
  • Display 模式用真實 Windows 虛擬顯示器，走 WebRTC H.264 串流並回傳輸入；備有 Cloudflare TURN 和 JPEG fallback。
  • Deck 模式直接在裝置瀏覽器跑 HTML／CSS／JS，文字與數據保持銳利。

Engineering

我碰到的工程問題

  • Display 模式管虛擬顯示器、影像串流與觸控鍵鼠回傳；Deck 模式則讓瀏覽器直接排版，小字才不會被視訊壓縮糊掉。
  • 不能只看主機端順不順，舊裝置必須調整更新頻率和傳輸方式才跟得上；公開展示全部直接拿實機畫面來拍。

Role & AI

我和 AI 怎麼分工

兩種模式的切換邊界由我定，Windows Host、瀏覽器客戶端跟打包發佈交給 coding agents 推進，再用家裡各種舊裝置實際擺上桌試用。

Trade-offs

實測後推翻與取捨

  • 試過幾條理論上更低延遲的串流路線，實測沒贏過現有方案就直接撤掉；在舊裝置上適度降 FPS 比疊複雜架構有效多了。

Outcome

成果

已開源並釋出 Windows 打包安裝檔，展示包含實機延伸螢幕、AI 額度看板與自訂資訊面板。
